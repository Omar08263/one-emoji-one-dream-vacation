One Emoji, One Dream Vacation: a program that writes one text to `/output/entry.txt` — a single emoji, nothing else, standing in for the trip of our dreams.

> 🏝

## Run it

```sh
node main.ts
```

The program writes `🏝` (U+1F3DD DESERT ISLAND, bare form — one character, four UTF-8 bytes) to `/output/entry.txt`, after checking it against the competition gate itself: 1–8 characters, not whitespace-only.
